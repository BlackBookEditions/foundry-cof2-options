Introduction

Chroniques Oubliées Fantasy 2e édition : Options

Ce module ajoute au système Chroniques Oubliées 2 des règles issues de l'Atlas d'Osgild et des règles optionnelles, sans modifier le système. Chaque règle s'active séparément depuis les paramètres du monde : tant qu'elle n'est pas activée, le jeu se déroule exactement comme avec le système seul.

Le module propose aujourd'hui une règle optionnelle :

  • le système de compétences de l'Atlas d'Osgild (chapitre « Systèmes alternatifs »), qui ajoute aux tests de caractéristique 22 compétences nommées, avec maîtrise, points de compétence et plafond de valeur.

Prérequis

  • Foundry VTT version 14.

  • Le système Chroniques Oubliées 2 (co2).

  • Le module Chroniques Oubliées Fantasy Livre des règles (cof2-base) est fortement recommandé : la maîtrise des compétences reconnaît les profils et les voies de peuple de ses compendiums. Un profil ou une voie de peuple créé à la main n'accorde aucune maîtrise.

Activation du système de compétences

Le MJ ouvre Paramètres du jeu > Configurer les paramètres, onglet du module Chroniques Oubliées Fantasy 2e édition : Options, et coche « Système de compétences (Atlas d'Osgild) ». Le monde doit être rechargé pour que le réglage prenne effet.

Une fois la règle active :

  • un onglet Compétences apparaît sur la fiche de chaque Personnage ;

  • les tests de caractéristique restent disponibles comme d'habitude ;

  • le bonus de +3 de la capacité de rang 1 des voies de peuple est remplacé par la maîtrise de deux compétences de peuple.

La règle ne concerne que les Personnages. Les Rencontres (PNJ et créatures) gardent leurs tests de caractéristique habituels.
