Les compétences

Le système de compétences de l'Atlas d'Osgild (p.223-227) remplace la lecture « large » des voies par une liste concrète de 22 compétences. Chaque compétence est liée à une caractéristique, parfois à plusieurs, et possède un bonus qui progresse avec les points de compétence. Toutes les compétences sont à +0 tant qu'aucun point n'y a été investi.

Le test de compétence

Un test de compétence se résout comme un test de caractéristique, auquel s'ajoute le bonus de la compétence :

Test de compétence = 1d20 + bonus de compétence + caractéristique, comparé à la difficulté.

Le jet passe par la fenêtre de jet habituelle du système : dé bonus ou dé malus (caractéristique supérieure, état affaibli…), seuil de critique, difficulté et points de chance fonctionnent comme pour un test de caractéristique. Voir @@page:fiche@@ pour le détail.

Quand une compétence est liée à plusieurs caractéristiques, c'est le joueur qui choisit celle du test, selon l'action entreprise : courir et sauter (AGI ou FOR), soulever un objet lourd (FOR) ou marcher longtemps (CON) pour l'Athlétisme ; monter à cheval (AGI) ou calmer une monture (CHA) pour l'Équitation. La description complète de chaque compétence se trouve dans l'Atlas d'Osgild (p.223-224).

Compétences et armure

Le malus d'armure s'applique automatiquement à tous les tests de compétence basés sur l'AGI ou la CON. Il est reporté dans le champ Malus de la fenêtre de jet.

Un personnage en armure qui tente un test d'Athlétisme choisit entre un test de FOR sans malus d'armure et un test d'AGI avec ce malus.

Valeur maximale

Le bonus d'une compétence ne peut pas dépasser niveau du personnage + 5, et jamais plus de +15. Le bouton d'augmentation de l'onglet Compétences se désactive une fois ce plafond atteint.
